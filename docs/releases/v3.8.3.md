# certs-maker v3.8.3

Release date: 2026-11-26 (Asia/Shanghai).

Rebuild the declared CLI platforms and versioned container images with Go 1.27.4 and the current container/build dependencies. Certificate formats and command behavior are unchanged by this maintenance release. Existing keys and certificates are not rotated or overwritten during the release process.

## Upgrade and rollback

Retain the previous exact program/image and back up configuration before rollout. Stop affected writers during replacement; validate the actual configured user path in staging. Restore the complete previous dependency lockfiles when rebuilding an older source version.

Full changes: https://github.com/soulteary/certs-maker/compare/v3.8.2...v3.8.3
